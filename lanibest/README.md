# laniBest

Live page: https://designsbygrandpa.com/websites/lanibest/

- `listings.json` holds the items shown on the page (Depop, Facebook Marketplace and Vinted, combined so each item appears once). The page loads it from GitHub, so editing this file updates the site within a few minutes without touching GoDaddy.
- Item photos are in `photos/` here, and the page loads them straight from GitHub.
- `index.html` is the copy of the page uploaded to GoDaddy. It only needs re-uploading if the design changes.
